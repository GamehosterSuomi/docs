## Minecraft Server Software

Different server types support different features.

| Software | Plugins | Mods |
| -------- | ------- | ---- |
| Vanilla  | No      | No   |
| Paper    | Yes     | No   |
| Fabric   | No\*    | Yes  |
| Forge    | No\*    | Yes  |

\*Standard Bukkit/Paper plugins are not supported natively.

Choose the server software that best matches your needs.
