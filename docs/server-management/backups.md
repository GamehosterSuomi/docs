# Server Backups

Backups help protect your server data from accidental deletion, corruption, or configuration mistakes.

## Creating a Backup

If backups are available in your server panel:

1. Open your server.
2. Navigate to the backup section.
3. Select the option to create a backup.
4. Wait for the process to complete.

## Restoring a Backup

1. Stop your server.
2. Open the backup section.
3. Select the backup you want to restore.
4. Confirm the restoration.
5. Start your server.

::: danger
Restoring a backup may overwrite your current server files. Save any important recent changes before restoring.
:::
