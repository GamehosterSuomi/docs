# SFTP connection problems

1. Choose **SFTP**, not plain FTP, and use the SFTP host and port shown in the panel; these can differ from the game address.
2. Check the panel's SFTP username and authentication method. Subuser permissions can restrict file access.
3. If the host key fingerprint changes unexpectedly, stop and verify it with support before accepting it.
4. For a timeout, try another network and check the local firewall. If connected but a transfer fails, check the destination, permissions and free disk space.

Tell support the exact error, time and client program, without sending passwords or private keys. See [SFTP](../server-management/sftp.md).
