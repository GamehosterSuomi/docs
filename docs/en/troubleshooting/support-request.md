# Writing a useful support request

1. Identify the service, when the issue began including time zone, what you expected and what happened.
2. Provide the exact error and whether everyone or one user is affected.
3. Give game, server software and modpack versions where relevant, plus recent changes.
4. Describe what you tried and the results; include relevant log excerpts or screenshots.
5. Remove passwords, API keys, recovery codes and unnecessary personal data before sending.

If data loss is possible, preserve existing files and backups. Tell support what has already been restored or deleted.
