# Minecraft says the server is full

1. Use `list` in the Java server console and compare the player count with `max-players` in `server.properties`.
2. To change the limit, see [server settings](../minecraft/server-properties.md); first check plan limits and resources.
3. Save and restart if needed. Try connecting and check the console.
4. If a proxy or plugin controls player limits, check its configuration too.

If the message persists despite available slots, send support the exact message, player count, server software and any relevant proxy or plugin.
