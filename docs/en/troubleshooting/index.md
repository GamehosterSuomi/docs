# Troubleshooting

Start by identifying whether the server cannot start, players cannot connect, or the game is running poorly. Record when the issue began and preserve relevant console messages before changing settings. The correct steps can differ by game and server software.

- [Server does not start](./server-not-starting.md)
- [Minecraft server crashes during startup](./minecraft-crash.md)
- [Cannot connect to a Minecraft server](./connection-issues.md)
- [Writing a useful support request](./support-request.md)
- [Minecraft reports that the server is full](./server-full.md)
- [Investigating memory errors](./memory-errors.md)
- [Server disk space is low](./disk-full.md)
- [SFTP connection fails](./sftp-connection.md)

## Before troubleshooting

1. Check the server console and read any errors.
2. Review server settings and recently installed plugins or mods.
3. Check available disk space and memory in the panel if shown. Make a backup before changing or replacing data.
4. Restart only when needed, after saving the relevant log and using the game's normal stop procedure.

If the problem continues, contact Gamehoster support and include relevant error messages.
