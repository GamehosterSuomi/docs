# Server disk space is low

A full disk can prevent saves, transfers or backups. Investigate usage before deleting files.

1. If saves are failing, stop the server gracefully and preserve the current state where possible.
2. Check disk use in the panel and inspect large files using the file manager or SFTP. How backups count against the limit depends on the service.
3. Move needed older files to safe storage. Delete only files whose purpose you understand and which you no longer need.
4. Check free space, start the server and watch for save errors.

Do not delete worlds, databases or unknown files to free space. If there is still insufficient space or data may be corrupt, contact support with the error and time.
