# Reviewing server activity

The panel's **Activity** view can help identify actions and their timing. It complements the game console and logs; not every in-game event necessarily appears here.

1. Sign in and select the correct server.
2. Open **Activity** if your permissions allow it.
3. Compare event times with the issue, checking the displayed time zone if available.
4. Check the same period in the console or server logs.

Record relevant events and times for support. Remove personal information, addresses and secrets before sharing logs. An event alone does not prove the cause.
