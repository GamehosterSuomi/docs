# Server management

Use the game panel to control your service, inspect its console and manage files. The exact views and limits depend on your service and account permissions. Before changing a production server, plan a suitable time, notify players and make a restorable backup.

## Basic maintenance

- Keep your server software up to date.
- Back up important data regularly.
- Check the console if problems occur.
- Install plugins and mods only from trusted sources.
