# Keeping a backup on your computer

Check whether your service allows backup downloads and what the backup includes.

1. Create a [backup](./backups.md) and wait for completion.
2. If downloading is available, open the backup's action menu in **Backups** and select **Download**. Check that the download completed and its size is plausible.
3. Store the copy securely: it may contain worlds, player data and secrets. Record its date and server software version.
4. Back up separate databases too, if used. Review the [restore plan](./restore-planning.md) and test recovery in a separate environment if available.

The backup's age determines how much subsequent work can be lost on restore. Make new copies according to how frequently the server changes.
