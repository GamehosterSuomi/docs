# Planning a backup restore

A restore returns data to an earlier point and can overwrite later work.

1. Select a completed backup from before the problem; check its date and contents.
2. Notify players and stop the server safely. If possible, make a separate backup of the current state.
3. Check whether the backup covers worlds, settings and plugin data. External databases and services may require separate backups.
4. Review the panel's restore options and whether they replace or delete existing files before confirming.

After restoration finishes, start the server and verify the console, world and settings. If the problem remains, retain both copies and tell support what was restored. See [backup instructions](./backups.md).
