# Checking startup settings

The **Startup** view may show startup variables. Available settings, permissions and effects depend on the game and server software.

1. Read the software documentation to understand the setting and its valid values.
2. Record the current value and make a [backup](./backups.md) if needed.
3. Stop the server, change only what is needed and save if required.
4. Start the server and check the console and result.

Do not guess the startup filename or Java version: an incorrect value can prevent startup. Ask support if the setting is locked or unclear. See [changing Minecraft version](../minecraft/version-change.md).
