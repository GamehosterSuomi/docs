# Server addresses and ports

The **Network** view may show addresses and ports allocated to your server. Availability and editing depend on your plan and permissions.

1. Open **Network** or check the address shown in the console view.
2. Identify the primary address and port and any additional allocations. Use only ports assigned to your server.
3. Check the game or plugin documentation for its required port and whether it uses TCP or UDP.
4. Contact support if the port is unavailable or the correct setting is unclear.

Entering a port in a configuration file does not allocate it. Changing the address can affect player connections and DNS. See [connecting a domain](../networking/domains.md).
