# Using the console and commands

The console displays server output and accepts commands supported by the game software.

1. Sign in to the [panel](https://panel.gamehoster.fi) and select your server.
2. Open the console and ensure the server is running if the command requires it.
3. Enter a supported command and read the response to verify the result.

For example, `list` displays connected players on a Minecraft Java server. Console commands generally omit the `/` used in game chat. Do not try unknown commands on a production server.

When investigating errors, find the first error and surrounding lines; later errors may be consequences. Remove credentials and other private information before sharing logs. Check with the owner if you lack console access; see [subusers](./subusers.md).
