# Using the File Manager

The file manager allows you to view and modify files stored on your game server.

## Opening the File Manager

1. Sign in to the control panel.
2. Select your server.
3. Open the file manager.

## Common Actions

Depending on the panel, you can:

- Upload and download files.
- Create directories.
- Edit text configuration files.
- Rename and delete files.

::: warning
Be careful when deleting files. Removing important server files may prevent your server from starting.
:::
