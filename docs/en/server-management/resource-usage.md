# Monitoring resource usage

The console view may show CPU, memory, disk and network usage. A brief high value alone does not identify the cause of a problem.

1. Record when the slowdown occurs and the number of players.
2. Compare resource usage during the issue and during a quiet period, against service limits if shown.
3. Check console errors and recent changes. For Minecraft see [performance troubleshooting](../minecraft/performance.md).
4. Change one thing at a time and compare under similar conditions.

A nearly full disk can prevent saves and memory pressure can contribute to crashes, but investigate the cause. Give support the time and relevant observations if needed.
