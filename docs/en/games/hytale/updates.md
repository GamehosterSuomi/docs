# Updating a Hytale server

Check current client/server protocol compatibility and mod requirements before updating.

1. Plan maintenance, notify players, stop the server and [back up](./backups.md) the world, settings and mods. Record the old version.
2. Check release notes and mod compatibility. Find out which update method Gamehoster supports for this service; ask support if unclear.
3. Update using that method and wait for completion. Update compatible mods according to their authors' instructions.
4. Start, check the console and any [authentication](./authentication.md), and test the world and player data with a compatible client.
5. If it fails, retain logs and backups; ask support about recovery before replacing files or opening a newer world in an older version.

Do not assume generic server auto-update commands apply to the managed installation. See [Hytale's server manual](https://support.hytale.com/hc/en-us/articles/45326769420827-Hytale-Server-Manual).
