# Authenticating a Hytale server

Gamehoster may handle authentication, or the console may request it. Follow the instructions shown for your service.

1. Start the server and inspect **Console**. If authentication succeeded or players can connect, no separate login is needed.
2. If device authentication is requested, Hytale's documented command is `/auth login device`. Use it only when appropriate for your service.
3. Open the Hytale login page shown in the console, check its address and enter the one-time code. Authorize it yourself using your Hytale account.
4. Return to the console and confirm success; follow any profile-selection instructions.

Keep codes and tokens secret. If authentication fails, check the error, account permissions and code expiry. Do not disable authentication as a workaround. Send support only relevant error text without credentials. See the [server manual](https://support.hytale.com/hc/en-us/articles/45326769420827-Hytale-Server-Manual).
