# Starting a Hytale server

You need an activated service, access to the [game panel](https://panel.gamehoster.fi/) and Hytale to test the connection. Initial installation may take longer than later starts.

1. Select your server in the panel. If it is missing, check activation and your account.
2. Open **Console** and check whether installation is still running. Select **Start** and watch the output; do not repeatedly start during installation.
3. If the console requests authentication, follow [authentication](./authentication.md). Keep one-time codes secret.
4. Wait for startup, check for errors, and copy the address and port shown in the panel.
5. [Connect](./connecting.md), test with another player and create a [backup](./backups.md) before changing mods or settings. Do not change the provider's Java version or startup command based on a generic installation guide.

See [Hytale's server manual](https://support.hytale.com/hc/en-us/articles/45326769420827-Hytale-Server-Manual).
