# Getting started with a Rust server

This guide covers Rust on PC. Check game, server version and platform compatibility; console editions may use different software.

1. Sign in to the [game panel](https://panel.gamehoster.fi/), select your Rust server and copy its actual address and game port. `g1.gamehoster.fi:2000` is an example of the format only.
2. Plan the server name, player limit and map. Check available [settings](./settings.md).
3. Follow [first startup](./first-start.md), wait for the map and [connect](./connecting.md).
4. Once the world works, configure trusted administrators and create a [backup](./backups.md) before adding plugins or making changes.

The player address and remote administration credentials are different. Do not share the RCON or panel password. See [Facepunch's guide](https://wiki.facepunch.com/rust/Creating-a-server).
