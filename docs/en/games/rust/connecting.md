# Connecting to a Rust server

Use the game port assigned in your panel, not an assumed default or the query port.

1. Check in the console that startup is complete and update your Rust client to a compatible version.
2. Copy the actual address and game port. `g1.gamehoster.fi:2000` is an example only.
3. Search the server list by name or open the game's F1 console and use the documented `connect` command, for example `connect g1.gamehoster.fi:2000`, replacing the example with your own address.
4. Follow any supported game password or access requirements. Never enter your panel or RCON password into the game.

If direct connection works but the server is not listed, ask support to check visibility and the separate query port. See [Facepunch's guide](https://wiki.facepunch.com/rust/Creating-a-server).
