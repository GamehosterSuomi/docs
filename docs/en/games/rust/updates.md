# Updating Rust

1. Notify players, stop the server and [back up](./backups.md) world, player data, settings and plugins.
2. Read Facepunch release notes and compatibility guidance for Oxide/uMod and plugins. Check whether the update forces a wipe.
3. Use Gamehoster's supported update method or ask support. A local SteamCMD guide does not establish the method for managed hosting.
4. Check whether the mod framework needs reinstalling. Facepunch warns that SteamCMD in a startup script can restore vanilla server files.
5. Start, check the version and logs, update clients and test connection and world. Do not rename old saves to bypass a forced wipe.

See [Facepunch's guide](https://wiki.facepunch.com/rust/Creating-a-server).
