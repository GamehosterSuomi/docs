# Getting started with a Valheim server

1. Sign in to the [game panel](https://panel.gamehoster.fi/) and select your Valheim server. Copy its actual address and port; `g1.gamehoster.fi:2000` illustrates the format only.
2. Check the service's Steam or crossplay mode and agree on a game server password. Available settings depend on the service.
3. Follow [first startup](./first-start.md), then [connect](./connecting.md). Confirm the intended world loads after a restart.
4. Make a [backup](./backups.md) before transferring worlds, changing settings or installing mods.

Do not share the panel password with players. See [Valheim's server manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
