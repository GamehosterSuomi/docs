# Troubleshooting Valheim

Distinguish startup, connection and world-loading problems; preserve console messages.

For startup, check the first error, version and recent changes. Check world name, save path and mod dependencies before changing anything; do not delete the world as a diagnostic step.

For connection problems, verify readiness, the panel address and port, compatible versions, game password and Steam/crossplay backend. Try a supported direct address or join code and check permission lists.

If the wrong world loads or data is missing, stop the server and preserve the current files. Check the selected world name and save path; follow [backups](./backups.md) if restoration is needed.

Send support the server name, time, versions, recent changes and first error, with credentials removed. See [Valheim's manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
