# Updating Valheim

1. Notify players, stop the server and [back up](./backups.md) the world and settings.
2. Check release notes and mod compatibility; updates can change saves or mod behavior. Platform releases may not appear simultaneously.
3. Use the update method provided by Gamehoster or ask support. Do not run local installation commands or replace startup scripts assuming they suit managed hosting.
4. Start, check console and server version, update players' clients to a compatible version and test the world.
5. If problems occur, keep old and new copies separately. Downgrading can require the pre-update world and matching server software; confirm recovery with support.

See [Valheim's manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
