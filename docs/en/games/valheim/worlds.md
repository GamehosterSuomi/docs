# Moving a Valheim world

1. Exit the world and copy the original on your device. Check Valheim's world manager for local versus cloud storage and export the correct version. Player characters and server worlds are separate data.
2. Stop the Gamehoster server and [back it up](./backups.md). Find its actual save path from service settings or support; local operating-system defaults may not apply.
3. Transfer all world files together using [SFTP](../../server-management/sftp.md), retaining names and structure. Do not overwrite the old world without a recoverable copy.
4. Select the transferred world name using the supported panel method, start and verify its buildings and progress. If a blank world appears, stop and check the files, path and selected name. Keep originals until verified.

See [Valheim's server manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
