# Connecting to a Valheim server

1. Ensure the server has started and your client version is compatible. Open Valheim's join-game view and add the server using its available address or join-code option.
2. Enter the actual address and port from the panel; `g1.gamehoster.fi:2000` is an example only. Select the server and enter its game password, not your panel password.
3. A Steam-backend server requires a compatible Steam client. Cross-platform play requires the crossplay backend and appropriate player settings. Crossplay supports public address and port, join code or server list; obtain a current code if available.

If the server is missing from the list, it may be hidden or the listing delayed. Try direct joining and check startup, version and password. Give support the exact error without passwords. See [Valheim's manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
