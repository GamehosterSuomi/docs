# Valheim server mods

Mod installation is separate from crossplay. Supported methods and platforms depend on each mod and the service.

1. Check the author's supported game version, dependencies, supported platforms and whether all clients need the mod.
2. Stop the server and make a complete [backup](./backups.md), including the world. Ask support for allowed installation methods and paths if undocumented.
3. Install one compatible mod and dependencies according to its instructions. Do not replace service startup files without understanding the effects.
4. Start, inspect logs and test connection before adding another mod. Update only to compatible mod and loader versions.

Removing a mod that adds world content may change saves; retain a pre-change copy. See [Valheim's manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
