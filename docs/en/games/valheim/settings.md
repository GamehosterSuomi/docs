# Valheim server settings

1. Stop the server and [back it up](./backups.md). Check service-specific startup settings; editing rights vary.
2. In Valheim, `-name` controls the displayed name, `-world` selects a world and `-public` affects listing visibility. Password and crossplay controls depend on your service. Never guess or change assigned ports.
3. Save only intended changes, start the server and check the console and connection. Changing the world name can select or create another world; it is not a safe rename.

World modifiers and presets depend on the game version. Record old values and verify the provider supports the method before changing startup arguments. See [Valheim's manual](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
