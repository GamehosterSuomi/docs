# Minecraft ping test

The [ping test](https://tools.gamehoster.fi/fi/tools/minecraft-ping-test/) estimates browser response time to Gamehoster's test location in Finland. The result is not directly the in-game ping or a performance measurement of your own server.

1. Open the test on the device and connection you intend to play with. Measurement starts automatically.
2. Wait for the result and read the response time in milliseconds. Use the page's control to repeat the measurement if needed.
3. When investigating a connection problem, compare, for example, wired and wireless connections. Measure several times at different times of day.

Browser and network load and routing affect the result. If the game lags, check its own connection, server load and [Minecraft performance](../minecraft/performance.md). A failed measurement alone does not prove the game server is offline.
