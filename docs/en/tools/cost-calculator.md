# Server cost calculator

The [server cost calculator](https://tools.gamehoster.fi/fi/tools/server-cost-calculator/) estimates the cost of a self-hosted server from your inputs.

1. Enter estimated average continuous **Teho (W)** (power) and the total electricity price per kilowatt-hour. Use measured consumption if possible and include transmission and taxes.
2. Enter the hardware purchase price and other monthly expenses if applicable. Check the monthly and yearly estimates and energy use.
3. You can select a Gamehoster plan for comparison. Check current prices using the page's pricing link and consider the billing period.
4. Optionally copy the estimate with **Kopioi laskelma** (copy calculation).

For example, continuous 100 W consumption uses 72 kWh in a 30-day month. Actual consumption varies with workload and operating hours; the comparison may not include every hardware or maintenance cost.
