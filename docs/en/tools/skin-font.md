# Skins and pixel text

## Downloading a skin

Open the [skin tool](https://tools.gamehoster.fi/fi/tools/skin-downloader/), enter a player name or UUID and select **Hae skini** (find skin). Inspect the 3D preview and use the download controls if a result is available. The view offers background and animation choices; GIF export requires an animation selection. The online lookup can fail even when the username is correct.

## Pixel font

Open the [pixel font generator](https://tools.gamehoster.fi/fi/tools/font-generator/), enter text and choose the font, color, size, optional shadow and bold styling. Check the preview and use **PNG** to download a transparent image. The page also offers font files; check their license before reuse.
