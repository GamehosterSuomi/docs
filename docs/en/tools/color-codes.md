# Color codes tool

[Color Codes](https://tools.gamehoster.fi/fi/tools/color-codes/) helps design colors and formatting for Minecraft text. The target software or plugin must support the selected code format.

1. Open **Tekstin värieditori** (text color editor) and enter text.
2. Add colors and formatting using the buttons and check the preview.
3. Select **Tulosteen koodimuoto** (output code format) for your target. Options include `§`, `&`, Paper / Spigot RGB and MiniMessage.
4. Copy the result into the setting specified by the plugin or other target's instructions and test it in game.

**Värikooditaulukko** (color code table) compares codes, and **MiniMessage-liukuvärit** is a separate MiniMessage gradient tool. Not every target supports every format. The text editor's output is not a complete `server.properties` line; use the [MOTD editor](./motd.md) for the server-list message.
