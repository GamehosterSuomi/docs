# Server icon converter

The [server icon converter](https://tools.gamehoster.fi/fi/tools/server-icon-converter/) crops an image into a 64 × 64 PNG icon for a Minecraft Java server.

1. Select **Valitse kuva** (choose image) and open a PNG, JPEG or WebP image. The tool displays file and image size limits by the chooser.
2. Choose **Rajaa neliöksi** (crop square) or **Sovita koko kuva** (fit entire image). Move and zoom the image in the preview or using the controls; choose **Pikselitarkka** for pixel-precise scaling if appropriate.
3. Check the server-list preview and select **Lataa PNG** (download PNG). The file is named `server-icon.png`.
4. Put the image in the Java server root next to `server.properties`, restart the server and refresh the in-game server list.

The tool says images stay in the browser. If the icon does not appear, check the name, location and that you uploaded it to the right server. See also the [server icon guide](../minecraft/server-icon.md).
