# Circle and sphere generators

Use the [circle generator](https://tools.gamehoster.fi/fi/tools/circle-generator/) to design a circle or oval and the [sphere generator](https://tools.gamehoster.fi/fi/tools/sphere-generator/) to preview a sphere or dome.

1. Select the shape, diameter, style and material. For a sphere, you can also choose a custom height.
2. Check the preview and block count. The grid and preview controls help you build the design.
3. Select **PNG** to download an image or **.schem** for a building schematic. Check compatibility with your software version.
4. If your server has WorldEdit, open **Tuo WorldEditillä** (import with WorldEdit) and follow the displayed paths and commands. Back up an existing world before pasting: the operation can change blocks.
