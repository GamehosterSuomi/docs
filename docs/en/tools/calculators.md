# Coordinate, tick and beacon calculators

## Coordinates

In the [coordinate calculator](https://tools.gamehoster.fi/fi/tools/coordinate-calculator/), choose the source dimension and enter X, Y and Z. Converting from the Overworld to the Nether divides X and Z by eight; Y stays the same. Check the result and copy the coordinates or command if needed. Existing portals also affect portal connections. The **Chunk ja Region** (chunk and region) tab shows the chunk, local position and region filename.

## Time

In the [tick calculator](https://tools.gamehoster.fi/fi/tools/tick-calculator/), change a time or tick field and read the corresponding result. At the default rate one second equals 20 game ticks; actual elapsed time can be longer when the server falls behind. `/time add` changes world time immediately, whereas the function identifier in the `/schedule` template must be replaced with your own.

## Beacon

In the [beacon calculator](https://tools.gamehoster.fi/fi/tools/beacon-calculator/), choose pyramid level, material and effects. The block count excludes the beacon itself. Open **Jo omistamasi palikat** (blocks already owned) if needed and compare the materials required. The beam must be able to travel upwards.
