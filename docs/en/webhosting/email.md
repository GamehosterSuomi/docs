# Setting up a mailbox

If your web hosting plan includes email, you can create a mailbox for your domain. Before starting, check where the domain's email is currently hosted.

## Create a mailbox

1. Open mail management in Plesk and select the correct domain.
2. Create a mailbox within your plan's limits and set a strong, unique password.
3. Check Gamehoster's instructions for the required email DNS records. If another email provider is in use, do not change its MX records without understanding the impact.
4. Use available webmail or configure an [email client](./email-client.md) with the provider's connection details.
5. Send and receive a test message using another address.

If necessary, check the spam folder, mailbox storage and DNS. Do not send your mailbox password in a support request.

See [Plesk's mail settings guide](https://docs.plesk.com/en-US/obsidian/customer-guide/mail-settings.69551/).
