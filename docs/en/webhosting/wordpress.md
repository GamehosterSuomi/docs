# Setting up WordPress

WordPress requires a compatible PHP environment and database. A public site also needs a working address. Check your plan's support and connect your domain to the hosting service.

## Install

1. Check that the target directory does not contain a site you want to keep. Back up if necessary.
2. If WP Toolkit is included, open it in Plesk and choose WordPress installation. Check the domain, installation directory and settings before confirming.
3. Create a secure administrator account and a unique password. Store the credentials safely.
4. Once installation is complete, open the site and sign in to WordPress administration. Check that [HTTPS](./ssl.md) works.
5. Set up backups and update WordPress, themes and plugins regularly.

WP Toolkit is a separate Plesk extension, and its availability in this hosting service has not been confirmed. If it is unavailable, use WordPress's official installation instructions and the database details supplied by your provider.

See [Plesk's WP Toolkit documentation](https://docs.plesk.com/en-US/obsidian/customer-guide/wp-toolkit.79128/).
