# Web hosting backups and restoration

Restoring a website may require both its files and database. Check whether email, settings and other necessary data are included; back them up separately if they are not.

## Create a backup

1. Check whether backups are available for your subscription in Plesk.
2. Select the correct site or subscription and check what the backup will contain.
3. Wait for the job to complete and check its status. If possible, keep a copy in a separate secure location.
4. Check the backup schedule, retention period and disk usage.

## Restore carefully

Before restoring, make a copy of the current state. Choose a restore point and check whether files, databases or settings will be restored. Restoration can overwrite newer data: for example, later orders may be lost from an online store's restored database.

Test the site after restoration, including sign-in and forms. If possible, practise restoring in a separate test environment.

See [Plesk's backup guide](https://docs.plesk.com/en-US/obsidian/customer-guide/backing-up-and-restoring-websites.69566/).
