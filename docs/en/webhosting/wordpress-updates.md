# Updating WordPress safely

WordPress, theme and plugin updates fix bugs and security issues. Check for updates regularly and monitor the site afterwards.

## Prepare and update

1. Make a restorable [backup](./backups.md) of both files and the database.
2. Check theme and plugin compatibility with the target WordPress and current PHP versions.
3. If possible, try the change on a separate test copy first. Plan a maintenance window for an online store.
4. Update through WordPress administration or an available WP Toolkit feature. Update in a controlled manner and watch for errors.
5. Test the home page, sign-in, important pages, forms and purchasing if applicable.

If a feature breaks, check the error and most recent change. Restore a compatible file and database backup if necessary; restoration can discard data created after the update. Automatic updates do not replace backups and monitoring.

See [Plesk's WP Toolkit documentation](https://docs.plesk.com/en-US/obsidian/customer-guide/wp-toolkit.79128/).
