# Installing a modpack

A modpack combines mods and configuration. Use the author's server package where available: a client pack can include client-only files.

The **More → Modpacks** function may be available. **Browse Modpacks** lets you search, view **Details** and select **Install**. A listing alone does not guarantee server compatibility; check the author's instructions and installation effects first.

1. Check Minecraft, mod loader and Java versions and resource requirements in the pack's instructions.
2. Confirm a suitable installation method is available; startup settings vary by pack.
3. Stop and back up before replacing files or reinstalling.
4. Follow the server installation instructions and transfer required files. Do not replace the provider's startup files or settings without understanding the effects.
5. Start and check the console for dependencies and errors. Install the matching pack version on the player's computer and test joining and world loading.

If startup fails, check Java, loader and server package instructions. Give support the pack name, version and relevant error.
