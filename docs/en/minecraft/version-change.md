# Changing your Minecraft server version

Changing versions affects worlds, mods, plugins and player compatibility. Schedule downtime and notify players.

The panel may offer **More → Versions**, where you can browse server software and Minecraft versions and check the listed Java requirement. Availability depends on the server. Review installation effects before confirming.

1. Check the target version's Java requirements and extension compatibility.
2. Stop and [back up](../server-management/backups.md) worlds, settings and extension data. Confirm you can restore it.
3. For a downgrade, use a backup made with the older version. Do not assume a world opened in a newer version is compatible with an older one.
4. Use the offered version change method or software installation instructions. Check whether reinstallation removes files.
5. Update compatible mods and plugins following their instructions. Do not replace JARs while running.
6. Start, watch the console, test joining with the correct client version and check the world and important functions. If unsuccessful, stop and restore both the previous software and matching backup.

See [Paper updating](https://docs.papermc.io/paper/updating/) and [troubleshooting](https://docs.papermc.io/paper/basic-troubleshooting/).
