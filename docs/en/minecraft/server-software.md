# Choosing Minecraft server software

Server software determines which extensions you can use. Check what is available for your server.

| Software | Purpose |
| --- | --- |
| Vanilla | Basic Minecraft features and Java datapacks. |
| Paper | Bukkit- and Paper-compatible plugins and server management. |
| Fabric, Forge or NeoForge | Mods made for the corresponding loader. |

Mods and plugins are not generally interchangeable. Check each extension's Minecraft version and dependencies. Hybrid software compatibility varies.

Before changing software, back up worlds, configuration and extensions; consult the target software's instructions for world and dimension migration and extension compatibility. Stop the server and use its offered installation method, first checking whether reinstallation deletes files. Start and check the console and world; retain the old backup for recovery.
