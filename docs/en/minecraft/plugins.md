# Installing Minecraft Plugins

Plugins allow you to add new features to your Minecraft server.

## Requirements

Your server must use compatible plugin-supporting software, such as Paper.

## Installation

1. Download a plugin compatible with your Minecraft version.
2. Stop your server.
3. Open the server file manager.
4. Navigate to the `plugins` directory.
5. Upload the plugin `.jar` file.
6. Start your server.

## Verify Installation

Check the console for plugin startup messages.

You can also use:

```text
plugins
```

This command is available on many Bukkit-compatible servers.

::: warning
Only install plugins from trusted sources.
:::
