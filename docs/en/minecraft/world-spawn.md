# Setting world spawn

World spawn is used, for example, for new players. A player's personal spawn such as a bed can affect later respawns. Plugins may override vanilla behavior.

1. Choose a safe location and record its coordinates.
2. In a Java console, for example, enter `setworldspawn 100 65 -20`, replacing the numbers with X, Y and Z. In chat use `/` and sufficient permissions.
3. Check the response and test with a new test player. Actual spawn may be near the point rather than exactly on the block.
4. For spawn or multiworld plugins, check their configuration and the correct world; plugin behavior can override the command.

If a player appears elsewhere, check personal spawn and plugins before issuing another command. See [Minecraft commands](https://www.minecraft.net/en-us/article/minecraft-commands).
