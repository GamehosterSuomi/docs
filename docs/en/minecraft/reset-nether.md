# Resetting the Nether

Regenerating the Nether removes its current terrain, buildings and other data. This is not a normal update requirement. Its storage location varies by server software and version.

1. Notify players and ask them to leave the Nether. Consult your software documentation to locate the Nether for the correct world.
2. Stop and take a complete backup of worlds and settings. Check how to restore it.
3. Test in a separate server copy first. Ensure the folder is the correct world's Nether, not the whole world or End.
4. Move the identified folder out of its active location following the software's instructions, retaining a separate copy. Start the server and try entering the Nether. The software may regenerate the missing dimension.
5. Check portals and gameplay; regenerated terrain will not retain old buildings. If the result is wrong, stop and restore the prior folder or backup.

Do not move or delete world files if the layout is unclear. See [Paper's migration guide](https://docs.papermc.io/paper/migration/).
