# Starting Your Server

This guide explains how to start your game server for the first time.

## Step 1: Open the Control Panel

Sign in and select your game server.

## Step 2: Start the Server

Click the **Start** button.

## Step 3: Check the Console

Watch the console for startup messages.

Some games require additional configuration before the server can start successfully.

## Step 4: Connect

Once the server is running, use its connection address and port to join from your game client.

::: warning
If the server fails to start, check the console for errors before trying again.
:::
