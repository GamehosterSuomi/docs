
# Accessing Your Server

After your game server has been activated, you can access it through the Gamehoster control panel.

## Step 1: Sign In

Open the Gamehoster control panel and sign in with your account.

## Step 2: Select Your Server

Find your server in the server list and select it.

## Step 3: Open the Console

The console allows you to view server output, enter commands, and monitor startup messages.

::: info
Your server may take a few moments to become available after activation.
:::
