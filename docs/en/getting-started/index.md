# Getting started with your game server

This section takes you from service activation to your first connection. Have your game panel account and the game ready; some games require a particular client version or additional configuration.

## Start here

1. [Sign in to the game panel and find your server](./accessing-server.md).
2. [Start the server and follow its console](./first-startup.md).
3. Copy the address and port shown for your service. An address such as `g1.gamehoster.fi:2000` is an example, not your assigned address.
4. Add the server in your game using its supported connection method. Check that the game edition and server versions are compatible.
5. Once you can connect, configure the game for your group and make a [backup](../server-management/backups.md) before substantial changes.

## If you get stuck

The console can show whether the server finished loading or why it stopped. If it will not start, use [startup troubleshooting](../troubleshooting/server-not-starting.md). If your game cannot connect, check the address, port, edition and version first. Features differ between games, so use your game's guide when available.

Do not share panel passwords or SFTP credentials with players. Give trusted helpers their own [limited access](../server-management/subusers.md) when needed.
