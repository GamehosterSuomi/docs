# Getting Started

Welcome to Gamehoster!

This documentation will help you get your game server up and running.

## First Steps

1. [Access your server](./accessing-server.md)
2. [Start your server](./first-startup.md)
3. Configure your game settings.
4. Invite your friends to join.
