
# Troubleshooting

Having trouble with your server? This section covers common problems.

## Common Issues

- [Server Not Starting](./server-not-starting.md)

## Before Troubleshooting

Try these steps:

1. Check your server's console.
2. Read any error messages.
3. Verify your configuration.
4. Check recently installed plugins or mods.
5. Restart the server if appropriate.

If the issue continues, contact Gamehoster support with the relevant error messages.
