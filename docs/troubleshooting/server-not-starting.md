# Server Not Starting

If your game server does not start, follow these steps.

## Step 1: Check the Console

Open the console and look for error messages.

These messages can help identify the cause of the problem.

## Step 2: Check Your Configuration

Incorrect settings or invalid configuration files may prevent startup.

Review any recent changes.

## Step 3: Check Plugins and Mods

If you recently installed a plugin or mod, verify that it is compatible with your server version.

Try disabling recently added extensions to isolate the problem.

## Step 4: Check Available Resources

Some games require significant memory or storage space.

Check the resource usage displayed in your server panel, if available.

## Step 5: Contact Support

If the server still fails to start, provide support with:

- The game and server software version.
- Relevant console errors.
- A description of the problem.
- Any changes made before the issue began.

::: tip
Providing the exact error message can make troubleshooting much faster.
:::
