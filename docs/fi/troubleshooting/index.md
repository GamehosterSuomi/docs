# Vianmääritys

Onko palvelimessasi ongelmia? Tästä osiosta löydät ohjeita yleisimpiin ongelmiin.

## Yleiset ongelmat

- [Palvelin ei käynnisty](./server-not-starting.md)

## Ennen vianmääritystä

Kokeile seuraavia vaiheita:

1. Tarkista palvelimesi konsoli.
2. Lue mahdolliset virheilmoitukset.
3. Tarkista palvelimen asetukset.
4. Tarkista hiljattain asentamasi lisäosat tai modit.
5. Käynnistä palvelin tarvittaessa uudelleen.

Jos ongelma jatkuu, ota yhteyttä Gamehosterin tukeen ja liitä mukaan olennaiset virheilmoitukset.
