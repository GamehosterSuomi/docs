# Minecraft ilmoittaa palvelimen olevan täynnä

Jos pelaaja saa ilmoituksen, että palvelin on täynnä, tarkista sekä nykyinen pelaajamäärä että palvelimen asetukset.

1. Tarkista pelaajat Minecraft Java -palvelimen konsolin `list`-komennolla ja vertaa määrää `server.properties`-tiedoston `max-players`-arvoon.
2. Jos haluat muuttaa rajaa, katso [palvelimen asetukset](../minecraft/server-properties.md). Tarkista ensin palvelupakettisi mahdolliset rajoitukset ja käytettävissä olevat resurssit.
3. Tallenna muutos ja käynnistä palvelin tarvittaessa uudelleen. Kokeile liittymistä ja tarkista konsolista virheilmoitukset.
4. Jos käytät välityspalvelinta tai pelaajarajaa muuttavaa lisäosaa, tarkista myös sen oma raja ja ohjeet.

Jos ilmoitus jatkuu, vaikka tilaa pitäisi olla, kerro tuelle ilmoitus, pelaajamäärä, palvelinohjelmisto ja mahdolliset välityspalvelimet tai pelaajarajoituksia hallitsevat lisäosat.
