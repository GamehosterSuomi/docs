# Hyvän tukipyynnön tekeminen

Tarkat tiedot auttavat selvittämään ongelman ilman, että sinun tarvitsee toistaa samoja kokeiluja.

## Kerää tiedot

1. Kirjaa palvelu ja ongelman alkamisaika aikavyöhykkeineen sekä kuvaus siitä, mitä odotit tapahtuvan ja mitä tapahtui.
2. Kirjoita tarkka virheilmoitus ja kerro, koskeeko ongelma kaikkia käyttäjiä vai vain yhtä.
3. Kerro pelin, palvelinohjelmiston ja tarvittaessa modpackin versiot sekä viimeisimmät muutokset.
4. Kuvaa jo kokeillut vaiheet ja niiden tulokset. Lisää olennainen lokikatkelma tai kuvakaappaus.
5. Tarkista ennen lähettämistä, etteivät aineistot sisällä salasanoja, API-avaimia, palautuskoodeja tai tarpeettomia henkilötietoja.

Jos epäilet tietojen häviämistä, säilytä nykyiset tiedostot ja varmuuskopiot. Kerro tuelle, mitä on jo palautettu tai poistettu, jotta seuraavat toimet voidaan suunnitella.
