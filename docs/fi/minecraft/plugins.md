# Minecraft-lisäosien asentaminen

Lisäosilla voit lisätä uusia ominaisuuksia Minecraft-palvelimellesi.

## Vaatimukset

Palvelimella on oltava lisäosia tukeva palvelinohjelmisto, kuten Paper.

## Asennus

1. Lataa Minecraft-versiosi kanssa yhteensopiva lisäosa.
2. Pysäytä palvelin.
3. Avaa palvelimen tiedostonhallinta.
4. Siirry `plugins`-kansioon.
5. Lataa lisäosan `.jar`-tiedosto palvelimelle.
6. Käynnistä palvelin.

## Asennuksen tarkistaminen

Tarkista konsolista lisäosien käynnistysviestit.

Voit myös käyttää seuraavaa komentoa:

```text
plugins
```

Komento toimii monilla Bukkit-yhteensopivilla palvelimilla.

::: warning Varoitus
Asenna lisäosia vain luotettavista lähteistä.
:::
