# Minecraft-palvelinohjelmiston valinta

Palvelinohjelmisto määrää, millaisia laajennuksia palvelin voi käyttää. Tarkista ennen valintaa, mitkä ohjelmistot palvelimellesi ovat saatavilla.

| Ohjelmisto | Käyttötarkoitus |
| --- | --- |
| Vanilla | Minecraftin perustoiminnot ja Java Editionin datapackit. |
| Paper | Bukkit- ja Paper-yhteensopivat lisäosat sekä palvelimen hallinta. |
| Fabric, Forge tai NeoForge | Kullekin modilataajalle tehdyt modit. |

Modit ja lisäosat eivät yleensä ole keskenään vaihdettavia. Tarkista myös Minecraft-versio sekä mahdolliset riippuvuudet jokaisen laajennuksen omasta ohjeesta. Hybridiohjelmistojen yhteensopivuus vaihtelee.

## Ennen ohjelmiston vaihtoa

1. Ota varmuuskopio maailmoista, asetuksista ja laajennuksista.
2. Selvitä maailman ja ulottuvuuksien siirto sekä laajennusten yhteensopivuus kohdeohjelmiston ohjeista.
3. Pysäytä palvelin ja käytä palvelimellesi tarjottua asennustapaa. Varmista etukäteen, poistaako uudelleenasennus tiedostoja.
4. Käynnistä palvelin ja tarkista konsoli sekä maailma. Säilytä vanha varmuuskopio mahdollista palautusta varten.
