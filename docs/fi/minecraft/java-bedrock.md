# Java- ja Bedrock-pelaajat samalla palvelimella

Minecraft Java Edition ja Bedrock Edition eivät normaalisti yhdistä suoraan toistensa palvelinohjelmistoihin. [Geyser](https://geysermc.org/wiki/geyser/setup/) mahdollistaa Bedrock-pelaajien liittymisen yhteensopivalle Java-palvelimelle. Se ei muuta Bedrock-palvelinta Java-palvelimeksi.

## Ennen asennusta

1. Tarkista Geyserin sivulta Java-palvelinohjelmistollesi sopiva versio ja tuetut peliversiot.
2. Selvitä, onko palvelimellesi saatavilla Geyserin tarvitsema lisäportti ja tarvittavat verkkoprotokollat. Tarve riippuu Geyserin yhteystavasta ja asetuksista; pyydä tarvittaessa apua tuelta.
3. Ota varmuuskopio. Jos Bedrock-pelaajilla ei ole Java-tiliä, selvitä myös [Floodgaten](https://geysermc.org/wiki/floodgate/) käyttöönotto ja tunnistautumisen vaikutukset.

## Asenna ja kokeile

1. Asenna palvelinohjelmistoasi vastaava Geyserin versio sen virallisen ohjeen mukaisesti.
2. Määritä käytettävissä oleva portti ja tunnistautuminen Geyserin ohjeen sekä palvelimen verkkoasetusten mukaan.
3. Käynnistä palvelin uudelleen ja tarkista konsolista, että Geyser latautui ilman virheitä.
4. Kokeile liittymistä Bedrock-laitteella palvelimen osoitteella ja Geyserille määritetyllä portilla. Java-pelaajat käyttävät edelleen Java-palvelimen osoitetta ja porttia.

Jos liittyminen epäonnistuu, vertaa Geyserin asetuksia käytettävissä olevaan porttiin ja tarkista tuetut versiot. Kaikki pelin ominaisuudet eivät välttämättä toimi täsmälleen samalla tavalla eri versioiden välillä.
