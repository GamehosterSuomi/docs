## Minecraftin palvelinohjelmistot


Eri palvelinohjelmistot tukevat eri ominaisuuksia.

| Ohjelmisto | Lisäosat | Modit |
| ---------- | -------- | ----- |
| Vanilla    | Ei       | Ei    |
| Paper      | Kyllä    | Ei    |
| Fabric     | Ei\*     | Kyllä |
| Forge      | Ei\*     | Kyllä |

\* Tavallisia Bukkit- ja Paper-lisäosia ei tueta suoraan.

Valitse tarpeisiisi sopiva palvelinohjelmisto.
