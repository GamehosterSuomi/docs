# Pelaajan UUID-muunnin

[Pelaajan UUID-muunnin](https://tools.gamehoster.fi/fi/tools/uuid-converter/) hakee Minecraft Java -pelaajan online-UUID:n ja laskee nimestä offline-UUID:n. Nämä tunnisteet ovat eri asioita.

1. Kirjoita Java-pelaajan nimi tai UUID hakukenttään ja valitse **Hae**.
2. Tarkista **Online-UUID**- ja **Offline-UUID**-tulokset. Voit valita muodon **Väliviivoilla** tai **Ilman väliviivoja** ja kopioida tarvitsemasi tunnisteen.
3. Jos käytät tunnistetta tiedoston tai oikeuksien etsimiseen, varmista palvelimen tunnistautumistapa ja palvelinohjelmiston tai välityspalvelimen ohje. Tee varmuuskopio ennen pelaajatiedostojen muuttamista.

Online-UUID perustuu haettuun pelaajaprofiiliin; offline-tunniste lasketaan nimestä. Välityspalvelimet ja lisäosat voivat vaikuttaa käytettyyn tunnisteeseen. Älä muuta `online-mode`-asetusta vain saadaksesi toisen tunnisteen. Katso [pelaajatietojen palautus](../minecraft/player-data-restore.md).
