# Palvelinkuvakkeen muunnin

[Palvelinkuvakkeen muunnin](https://tools.gamehoster.fi/fi/tools/server-icon-converter/) rajaa kuvasta Minecraft Java -palvelimen 64 × 64 pikselin PNG-kuvakkeen.

1. Valitse **Valitse kuva** ja avaa PNG-, JPEG- tai WebP-kuva. Työkalu ilmoittaa tiedoston ja kuvan koon rajat valintakohdan yhteydessä.
2. Valitse **Rajaa neliöksi** tai **Sovita koko kuva**. Siirrä ja suurenna kuvaa esikatselussa tai säätimillä; valitse tarvittaessa **Pikselitarkka** skaalaus.
3. Tarkista palvelinlistan esikatselu ja valitse **Lataa PNG**. Tiedoston nimi on `server-icon.png`.
4. Siirrä kuva Java-palvelimen juureen `server.properties`-tiedoston viereen ja käynnistä palvelin uudelleen. Päivitä palvelinlista pelissä.

Työkalun sivun mukaan kuvat pysyvät selaimessa. Jos kuvake ei näy, tarkista nimi, sijainti ja että latasit uuden kuvan oikealle palvelimelle. Katso myös [palvelinkuvakkeen ohje](../minecraft/server-icon.md).
