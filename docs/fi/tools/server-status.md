# Minecraft-palvelimen tilatarkistus

[Palvelimen tilatarkistus](https://tools.gamehoster.fi/fi/tools/server-status-checker/) hakee Minecraft **Java Edition** -palvelimen julkisen tilavastauksen. Se ei kirjaudu sisään palvelimelle tai tarkista pelaajan liittymisoikeutta.

1. Kirjoita **Palvelimen osoite** -kenttään Java-palvelimen osoite. Käytä palvelimen ilmoittamaa porttia, jos se täytyy antaa osoitteen yhteydessä.
2. Valitse **Tarkista palvelin** ja odota vastausta.
3. Onnistuneessa tarkistuksessa näkyy palvelinlistan esikatselu, jossa voi olla viesti ja pelaajamäärä. Näytetyt tiedot riippuvat palvelimen vastauksesta.

Jos tilaa ei saada, tarkista osoite ja portti sekä palvelimen käynnistyminen konsolista. Verkko, DNS tai palvelimen tila-asetukset voivat vaikuttaa tulokseen. Epäonnistunut tilakysely ei yksin todista, että kaikki pelaajat eivät voisi liittyä. Katso [yhteysongelmien ohje](../troubleshooting/connection-issues.md).
