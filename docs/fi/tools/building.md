# Ympyrä- ja pallogeneraattorit

[Ympyrägeneraattorilla](https://tools.gamehoster.fi/fi/tools/circle-generator/) voit suunnitella ympyrän tai ovaalin; [pallogeneraattori](https://tools.gamehoster.fi/fi/tools/sphere-generator/) näyttää pallon tai kupolin.

1. Valitse muoto, halkaisija, tyyli ja materiaali. Pallolle voi myös valita oman korkeuden.
2. Tarkista esikatselu ja palikkamäärä. Ruudukko ja esikatselun säätimet auttavat rakentamaan mallin.
3. Valitse **PNG** kuvan lataamiseen tai **.schem** rakennusmallia varten. Tarkista tiedoston käyttö ohjelmistosi versiossa.
4. Jos palvelimella on WorldEdit, avaa työkalun **Tuo WorldEditillä** -ohje ja noudata näytettyjä tiedostopolkuja ja komentoja. Ota varmuuskopio ennen mallin sijoittamista olemassa olevaan maailmaan: liittäminen voi muuttaa palikoita.
