# Ensimmäinen käynnistys

Näin käynnistät pelipalvelimesi ensimmäistä kertaa.

## Vaihe 1 – Avaa hallintapaneeli

Kirjaudu sisään ja valitse pelipalvelimesi.

## Vaihe 2 – Käynnistä palvelin

Napsauta **Start**-painiketta.

## Vaihe 3 – Tarkista konsoli

Seuraa käynnistysviestejä konsolissa.

Joissakin peleissä palvelin vaatii lisäasetuksia ennen kuin se voi käynnistyä.

## Vaihe 4 – Yhdistä palvelimelle

Kun palvelin on käynnissä, yhdistä siihen pelistäsi palvelimen osoitteella ja portilla.

::: warning Varoitus
Jos palvelin ei käynnisty, tarkista konsolin virheilmoitukset ennen kuin yrität uudelleen.
:::
