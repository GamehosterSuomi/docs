# Palvelimelle kirjautuminen

Kun pelipalvelimesi on aktivoitu, voit hallita sitä Gamehosterin hallintapaneelissa.

## Vaihe 1 – Kirjaudu sisään

Avaa Gamehosterin hallintapaneeli ja kirjaudu sisään tunnuksillasi.

## Vaihe 2 – Valitse palvelimesi

Etsi palvelimesi palvelinluettelosta ja valitse se.

## Vaihe 3 – Avaa konsoli

Konsolissa voit tarkastella palvelimen tulosteita, antaa komentoja ja seurata käynnistysviestejä.

::: info Huomio
Voi kestää hetken, ennen kuin palvelimesi on käytettävissä aktivoinnin jälkeen.
:::
