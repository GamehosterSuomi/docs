# Pelipalvelimen hallintapaneeliin kirjautuminen

Pelipaneelissa voit seurata palvelimen tilaa ja hallita sen tiedostoja. Käytettävissä olevat toiminnot riippuvat palvelusta ja käyttäjäsi oikeuksista.

## Vaihe 1 – Kirjaudu sisään

Avaa [Gamehosterin pelipaneeli](https://panel.gamehoster.fi/), tarkista osoite selaimen osoiteriviltä ja kirjaudu omilla tunnuksillasi. Jos kirjautuminen ei onnistu, käytä palvelun toimittamia salasanan palautusohjeita.

## Vaihe 2 – Valitse palvelimesi

Etsi palvelimesi **Servers**-luettelosta ja valitse se. Jos sinulla on useampi palvelin, tarkista nimi ennen muutosten tekemistä.

## Vaihe 3 – Avaa konsoli

**Console**-näkymässä voit seurata palvelimen tulosteita ja käynnistysviestejä sekä antaa sen tukemia komentoja. **Files** avaa tiedostonhallinnan, **Backups** varmuuskopiot ja **Settings** palvelimen asetuksia. Näkymien saatavuus voi vaihdella.

::: info Huomio
Palvelun käyttöönotto voi kestää aktivoinnin jälkeen. Jos palvelin ei näy, tarkista oikea tili ja tilauksen tila sekä mahdollinen alikäyttäjäkutsu. Jos ongelma jatkuu, ota yhteys Gamehosterin tukeen; älä lähetä salasanaasi.
:::
