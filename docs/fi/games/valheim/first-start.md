# Valheimin ensimmäinen käynnistys

Ensimmäisellä käynnistyksellä palvelin luo tai lataa maailman; odota tämän valmistumista ennen liittymistä.

1. Valitse pelipaneelissa Valheim-palvelin. Tarkista saatavilla olevista asetuksista palvelimen nimi, maailman nimi, salasana ja haluttu Steam- tai crossplay-tila. Älä muuta palveluntarjoajan määräämiä portteja arvaukseen.
2. Avaa **Console** ja valitse **START**. Seuraa, onko ohjelman latauksessa tai maailman luomisessa virheitä.
3. Valheimin valmistajan ohjeen mukaan `Game server connected` ilmoittaa palvelimen olevan valmis yhteyksiä varten. Odota myös mahdollisen crossplay-yhteyden valmistumista.
4. Kokeile liittyä osoitteella tai crossplayn liittymiskoodilla ja tarkista pelissä, että maailma on oikea.
5. Pysäytä palvelin paneelin pysäytystoiminnolla ja odota, että se sammuu kokonaan; käynnistä uudelleen ja tarkista sama maailma.

Jos palvelin pysähtyy, säilytä ensimmäinen virhe ja tutki [vianmääritys](./troubleshooting.md). Älä korvaa käynnistysskriptiä paikallisen palvelimen ohjeen perusteella.

Lisätietoja: [Valheimin virallinen palvelinohje](https://www.valheimgame.com/support/a-guide-to-dedicated-servers/).
