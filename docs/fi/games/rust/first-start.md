# Rust-palvelimen ensimmäinen käynnistys

Rust luo tai lataa kartan ja tallennukset käynnistyksessä. Ensimmäinen käynnistys ja kartan luonti voivat kestää tavallista kauemmin.

1. Valitse palvelin pelipaneelissa. Tarkista tarjolla olevista asetuksista palvelimen nimi, pelaajaraja ja suunniteltu kartta. Älä muuta peli-, kysely- tai hallintaportteja arvaamalla.
2. Avaa **Console** ja valitse **START**. Odota, että käynnistys ja maailman lataus valmistuvat; älä paina käynnistystä toistuvasti.
3. Lue mahdolliset virheet kokonaisuudessaan. Palvelimen näkyminen paneelissa käynnissä ei yksin varmista, että peli ottaa jo yhteyksiä vastaan.
4. Kokeile Rustin asiakkaalla liittymistä ja tarkista, että olet oikeassa maailmassa. Pysäytä palvelin hallitusti ja varmista uudelleenkäynnistyksessä, että tallennettu maailma latautuu.

Jos palvelin pysähtyy tai kartta ei lataudu, katso [vianmääritys](./troubleshooting.md) ja säilytä loki ennen uusia kokeiluja.

Lisätietoja: [Facepunchin Rust-palvelinohje](https://wiki.facepunch.com/rust/Creating-a-server).
