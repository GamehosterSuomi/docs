# Hytale-palvelimen ohjeet

Hytale-palvelimella voit ylläpitää yhteistä maailmaa, joka pysyy käytössä myös oman pelisi sulkemisen jälkeen. Nämä ohjeet auttavat Gamehosterin hallintapaneelissa ja pelin omissa asetuksissa. Pelin ja palvelimen versiot sekä käytettävissä olevat paneelin ominaisuudet voivat muuttua.
