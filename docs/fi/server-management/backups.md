# Palvelimen varmuuskopiot

Varmuuskopiot auttavat suojaamaan palvelimesi tietoja tahattomalta poistamiselta, tietojen vioittumiselta ja asetusvirheiltä.

## Varmuuskopion luominen

Jos hallintapaneelissa on varmuuskopiointitoiminto, toimi näin:

1. Avaa palvelimesi hallintapaneelissa.
2. Siirry varmuuskopioihin.
3. Valitse varmuuskopion luontitoiminto.
4. Odota, että varmuuskopio valmistuu.

## Varmuuskopion palauttaminen

1. Pysäytä palvelin.
2. Avaa varmuuskopiot.
3. Valitse palautettava varmuuskopio.
4. Vahvista palautus.
5. Käynnistä palvelin.

::: danger Vaara
Varmuuskopion palauttaminen voi korvata palvelimen nykyiset tiedostot. Tallenna tärkeät viimeaikaiset muutokset erikseen ennen palauttamista.
:::
