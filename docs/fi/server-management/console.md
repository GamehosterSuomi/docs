# Konsolin käyttö ja komennot

Konsoli näyttää palvelinohjelmiston tulosteita ja ottaa vastaan sen tukemia komentoja. Komennot ja niiden vaikutukset riippuvat pelistä ja palvelinohjelmistosta.

## Komennon suorittaminen

1. Kirjaudu [hallintapaneeliin](https://panel.gamehoster.fi) ja valitse palvelin.
2. Avaa konsoli ja varmista, että palvelin on käynnissä, jos komento sitä edellyttää.
3. Kirjoita palvelinohjelmiston tukema komento konsolin syötekenttään ja lähetä se.
4. Lue vastaus ja tarkista, että haluttu muutos tapahtui.

Esimerkiksi Minecraft Java -palvelimen konsolissa `list` näyttää kirjautuneet pelaajat. Konsoliin kirjoitettaviin Minecraft-komentoihin ei yleensä tarvita pelin chatissa käytettävää `/`-etuliitettä. Älä kokeile tuntemattomia komentoja tuotantopalvelimella.

## Virheiden selvittäminen

Etsi ensimmäinen virheilmoitus ja sen ympärillä olevat rivit: myöhempi virhe voi olla seurausta aiemmasta. Kopioi tarvittaessa riittävä osa viesteistä tukipyyntöön ja kerro, milloin ongelma alkoi sekä mitä muutit. Poista viesteistä salasanat, tunnukset ja muut yksityiset tiedot ennen jakamista.

Jos konsoliin tai komentoihin ei ole pääsyä, tarkista palvelimen omistajalta käyttöoikeutesi. Katso myös [alikäyttäjät ja käyttöoikeudet](./subusers.md).
