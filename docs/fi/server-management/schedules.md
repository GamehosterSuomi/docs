# Ajastetut tehtävät

Ajastuksilla voit automatisoida ylläpitotehtäviä, jos palvelusi ja käyttöoikeutesi sallivat sen. Pterodactylin tehtävä voi esimerkiksi lähettää komennon, muuttaa palvelimen virtatilaa tai luoda varmuuskopion. Käytettävissä olevat toiminnot ja rajoitukset riippuvat palvelimen asetuksista.

1. Valitse sopiva ajankohta ja varmista ajastuksen aikavyöhyke tuelta, jos sitä ei näytetä.
2. Avaa **Schedules**, valitse **New schedule**, nimeä ajastus ja täytä viisi cron-kenttää. **Show cheatsheet** näyttää esimerkkejä.
3. Tarkista **Only when server is online** ja **Schedule enabled** ja luo ajastus. Lisää tehtävät haluamassasi järjestyksessä. Pelkkä ajastuksen luominen ei lisää tehtävää. Käytä tuettuja komentoja ja tarkista viiveet.
4. Tarkista seuraava suoritusajankohta, jos se näytetään, ja seuraa koesuoritusta. Varmuuskopioita varten tarkista vapaa tila ja varmuuskopioiden määräraja, varmista kopioiden valmistuminen ja suunnittele [palautus](./restore-planning.md).

Jos tehtävä ei käynnisty, tarkista ajastuksen käyttöönotto, aikavyöhyke, rajoitukset ja konsolin virheilmoitukset. Jotkin tehtävät edellyttävät, että palvelin on käynnissä. Lähetä tarvittaessa olennaiset tiedot tuelle.
