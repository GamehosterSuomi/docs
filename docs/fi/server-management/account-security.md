# Pelipaneelin tilin suojaaminen

Pelipaneelin tunnuksella voi hallita palvelimia, joihin tililläsi on oikeus. Käytä yksilöllistä salasanaa ja ota kaksivaiheinen tunnistautuminen käyttöön, jos se on tilisi asetuksissa tarjolla.

## Suojaa tili

1. Avaa [pelipaneeli](https://panel.gamehoster.fi/) ja tarkista selaimen osoite ennen kirjautumista.
2. Avaa **Account Settings** ja tarkista tilin käytettävissä olevat suojausasetukset.
3. Jos otat kaksivaiheisen tunnistautumisen käyttöön, noudata paneelin ohjetta ja säilytä mahdolliset palautuskoodit turvallisessa paikassa erillään tunnistautumislaitteesta.
4. Anna muille omat [alikäyttäjäoikeudet](./subusers.md), älä yhteistä salasanaa.

Jos epäilet tilin joutuneen vääriin käsiin, vaihda salasana ja tarkista palvelinten käyttäjät ja muutokset. Ota yhteys tukeen, jos et pääse tilille tai tarvitset apua käyttöoikeuksien palauttamisessa. Älä lähetä salasanoja tai palautuskoodeja tukipyyntöön.
