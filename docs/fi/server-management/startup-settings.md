# Käynnistysasetusten tarkistaminen

**Startup**-näkymässä voi olla käynnistysmuuttujia. Käytettävissä olevat asetukset, käyttöoikeudet ja asetusten vaikutukset riippuvat pelistä ja palvelinohjelmistosta.

1. Tarkista ohjelmiston ohjeista asetuksen merkitys ja sallitut arvot.
2. Kirjaa nykyinen arvo muistiin ja ota tarvittaessa [varmuuskopio](./backups.md).
3. Pysäytä palvelin, muuta tarvittavat asetukset ja tallenna tarvittaessa.
4. Käynnistä palvelin ja tarkista konsoli sekä muutoksen vaikutus.

Älä arvaa käynnistystiedoston nimeä tai Java-versiota, sillä virheellinen arvo voi estää käynnistymisen. Kysy tuelta, jos asetus on lukittu tai epäselvä. Katso [Minecraft-version vaihtaminen](../minecraft/version-change.md).
