# Resurssien käytön seuraaminen

Pelipaneelin konsolinäkymässä voi seurata palvelimen suorittimen, muistin, levytilan ja verkkoliikenteen käyttöä. Näytetyt arvot ovat tilannekuva; hetkellinen korkea arvo ei yksin kerro ongelman syytä.

## Selvitä kuormitus

1. Kirjaa, milloin hidastuminen alkaa ja montako pelaajaa on paikalla.
2. Tarkastele resurssien käyttöä ongelman aikana sekä rauhallisena aikana. Vertaa arvoja palvelun rajoihin, jos ne näkyvät.
3. Tarkista konsolin virheet ja viimeisimmät muutokset. Jos kyseessä on Minecraft, katso [suorituskyvyn vianmääritys](../minecraft/performance.md).
4. Tee yksi muutos kerrallaan ja vertaa tilannetta vastaavalla pelaajamäärällä.

Lähes täysi levy voi estää tallennukset ja suuri muistinkäyttö voi liittyä kaatumiseen, mutta syy täytyy selvittää erikseen. Kerro tuelle kellonaika, palvelun nimi ja olennaiset havainnot, jos tarvitset apua.
