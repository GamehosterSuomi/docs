# Palvelimen tapahtumien tarkistaminen

Pelipaneelin **Activity**-näkymä voi auttaa selvittämään, mitä paneelissa tehtiin ja milloin. Se täydentää pelipalvelimen konsolia ja lokitiedostoja: kaikki pelin sisäiset tapahtumat eivät välttämättä näy paneelin tapahtumissa.

1. Kirjaudu paneeliin ja valitse oikea palvelin.
2. Avaa **Activity**, jos näkymä on käytettävissä oikeuksillasi.
3. Vertaa tapahtumien ajankohtaa ongelman alkamisaikaan. Tarkista paneelin näyttämä aikavyöhyke, jos se on saatavilla.
4. Tarkista vastaava ajankohta myös konsolista tai palvelinohjelmiston lokista.

Kirjaa havaittu tapahtuma ja aika ennen yhteydenottoa tukeen. Älä julkaise lokia sellaisenaan, jos siinä näkyy henkilötietoja, osoitteita tai salaisuuksia. Tapahtuman näkyminen ei yksin kerro ongelman syytä.
