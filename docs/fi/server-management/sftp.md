# Yhdistäminen SFTP:llä

SFTP:llä voit siirtää tiedostoja turvallisesti tietokoneesi ja pelipalvelimesi välillä.

## Vaatimukset

Tarvitset seuraavat tiedot ja ohjelman:

- SFTP-asiakasohjelman, kuten FileZillan tai WinSCP:n.
- Palvelimesi SFTP-palvelinosoitteen ja portin.
- SFTP-kirjautumistunnuksesi.

## Yhdistäminen

1. Avaa SFTP-asiakasohjelma.
2. Syötä hallintapaneelissa näkyvä palvelinosoite ja portti.
3. Syötä käyttäjätunnuksesi ja salasanasi.
4. Yhdistä palvelimelle.
5. Siirrä tarvitsemasi tiedostot.

::: warning Varoitus
Älä jaa SFTP-kirjautumistunnuksiasi muiden kanssa.
:::
